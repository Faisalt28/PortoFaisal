# Faisal — Portfolio Website

Personal portfolio website built with modern web technologies showcasing software engineering projects across Web Development, Mobile Android Development, and Machine Learning.

## 🚀 Tech Stack

- **Framework:** React 19 (Vite)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Icons:** Lucide React, Tabler Icons

## 📂 Featured Projects

1. **AcheeZ** — Multi-account personal finance management (React.js, Cloudflare Workers & D1, Zustand, Recharts)
2. **RS MediTrack** — Hospital staff scheduling & attendance system (React.js, TypeScript, Cloudflare)
3. **Frameify** — Interactive Unsplash visual exploration platform (React.js, Radix UI, Framer Motion)
4. **ArtoZ** — Offline-first student finance Android app (Kotlin, Android Studio, Room, MVVM, Coroutines)
5. **FindThem** — Student housing & directory geospatial Android app (Kotlin, Google Maps SDK, Room)
6. **Sistem Rekomendasi Film** — Content-Based Filtering film recommendation (Python, Scikit-learn, TF-IDF, Gradio)

## 🛠️ Development

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```
